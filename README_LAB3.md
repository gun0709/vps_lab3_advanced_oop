# Лабораторная работа №3: ООП в ИБ (Python)

Данный репозиторий содержит лабораторную работу по разработке объектно-ориентированного анализатора событий безопасности.

## 🎯 Цели работы
1. Освоить фабричные методы (`@classmethod`) и геттеры/сеттеры (`@property`).
2. Научиться выносить независимые утилиты в статические методы (`@staticmethod`).
3. Написать собственный декоратор-враппер (`@audit_logger`) для безопасного перехвата ошибок и аудита функций.
4. Использовать магические методы (`__contains__`, `__len__`, `__repr__`) для создания удобных интерфейсов.
5. Обеспечить 100% покрытие типами данных (Type Hints) и прохождение проверок `mypy` и `unittest`.

---

## 📂 Структура проекта

* `advanced_soc_template.py` — заготовка кода с аннотациями типов и заглушками (переименуйте или скопируйте в `advanced_soc.py`).
* `advanced_soc.py` — основной файл с вашим кодом реализации классов и декоратора.
* `test_advanced_soc.py` — автоматические юнит-тесты (модуль `unittest`).
* `.github/workflows/validate-lab.yml` — конфигурация автоматической проверки на GitHub Actions.

## 🚀 Порядок выполнения

### 1. Форк и Клонирование
1. Сделайте **Fork** этого репозитория в свой аккаунт GitHub.
2. Клонируйте свой форк на локальный компьютер:
   ```bash
   git clone https://github.com/ВАШ_USERNAME/vps_lab3_advanced_oop.git
   cd vps_lab3_advanced_oop
   ```

### 2. Реализация кода
Переименуйте файл-шаблон `advanced_soc_template.py` в `advanced_soc.py` (или создайте `advanced_soc.py`) и реализуйте:
* Класс `SecurityEvent` (фабрики `from_syslog`, `from_dict`, свойства `severity` и `is_critical`).
* Класс `IPUtils` (статические методы `is_private` и `mask_ip`).
* Класс `BlacklistManager` (магические методы `__contains__`, `__len__`, `__repr__`).
* Декоратор `@audit_logger`.

### 3. Локальное тестирование
Перед отправкой на GitHub обязательно проверьте код на своем компьютере:

```bash
# 1. Проверка типов mypy
mypy --disallow-untyped-defs advanced_soc.py

# 2. Запуск автотестов
python3 -m unittest test_advanced_soc.py -v
```

### 4. Отправка решений на GitHub
```bash
git add advanced_soc.py
git commit -m "Реализован модуль advanced_soc с классами и декоратором"
git push origin main
```
После этого создайте **Pull Request** в оригинальный репозиторий преподавателя.
